# Project-04: Blog Application CI/CD Deployment on Amazon EKS

## Project Overview

This repository contains proof screenshots of Project-04, demonstrating the CI/CD pipeline and deployment of a three-tier Blog Application using AWS and DevOps tools.

## Technologies Used

- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Containerization:** Docker
- **Cloud:** AWS, Amazon EKS, Amazon ECR
- **CI/CD:** GitHub Actions
- **Code Quality:** SonarQube
- **Security Scanning:** Trivy
- **Artifact Repository:** Nexus Repository
- **Monitoring:** Prometheus and Grafana

## Proof Screenshots

This repository contains screenshots showing the project workflow, successful CI/CD pipeline execution, EKS deployment, container image publishing, code analysis, security scanning, and monitoring setup.

## Project Status

The main application deployment and CI/CD workflow have been tested successfully. The latest verified GitHub Actions run completed all five jobs successfully.
